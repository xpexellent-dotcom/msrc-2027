## Acceptance criteria and verification

- Both About routes return HTTP 200 with exactly one localized H1, page title, description,
  correct HTML language/direction, breadcrumb and shared navigation. Unsupported locale
  routing remains a genuine 404.
- Header/footer About links reach the new locale route; language switching preserves the
  current page, query and hash. Home/participation/program links reach existing destinations.
- Visitor understands edition, institution, organizing club, purpose and intended community
  without interpreting community context as eligibility. Draft status and closed participation
  remain visible. No unavailable action becomes an enabled submission/registration control.
- Desktop/mobile and EN/AR layout, narrow-phone/200% text overflow, keyboard skip/focus,
  semantics, contrast and reduced-motion behavior receive actual browser verification.
- Application lint/type/unit/build checks pass. Test and review evidence is recorded in
  `docs/PROGRESS.md`; automated accessibility checks do not replace final human review.
